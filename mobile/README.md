# mobile · M 端移动协同层（Flutter 工作台）

面向农户/合作社的移动工作台，支持**弱网离线缓存、扫码发货、语音唤醒 AI 农技问答**。

## 技术栈（规划）

- Flutter（Android / iOS）
- 状态管理：Riverpod / Bloc（按团队偏好二选一）
- 本地离线：SQLite / Hive 缓存
- 扫码：`mobile_scanner`
- 语音：ASR（对接 ai-service `/ai/asr`）+ TTS 播报（可选）
- 网络：Dio + 后端 `/api/*`（经网关）

## 页面/功能规划

```text
/login                    农户/合作社登录
/home                    工作台首页
/qa                      农技问答（语音输入 → RAG 答复 → 语音播报）
/ship                    扫码发货（出库/交接）
/inventory                库存台账（离线可查）
/orders                   我的订单/物流交接
```

## 核心能力规划

| 能力 | 说明 | 状态 |
|------|------|------|
| 语音农技问答 | 语音→转写→RAG→答复/播报 | 规划中 |
| 扫码发货 | 出库/交接扫码 + 后端幂等 | 规划中 |
| 弱网离线 | 本地缓存、断点续传、联网同步 | 规划中 |
| 库存台账 | 合作社/农户库存管理 | 规划中 |

## 对接约定（规划）

- 业务接口：backend `/api/*`（经网关，Tenant ID 隔离）
- AI 接口：ai-service `/ai/*`
