# h5 · C 端消费引流层（极致轻量 H5）

面向消费者的**极致轻量 H5**，用于在微信群/社群/公众号中快速下单、抢购，
无需下载 App。登录复用微信授权（openid），弱网可用、首屏体积小。

## 技术栈（规划）

- 移动端优先的轻量方案：Next.js 静态导出 或 Vite + React/Vue（按体积与团队偏好二选一）
- Tailwind CSS（可选，样式极简）
- 微信 JS-SDK（授权、分享）

> 选型决策：C 端追求"极致轻量"，优先保证首屏与分享打开速度；
> 若以体积为准，可采用 Vite + 按需组件，产物静态托管。

## 页面规划

```text
/index           商品列表（首页推荐/秒杀入口）
/product/[id]    商品详情（价格、库存、产地故事）
/order/checkout  下单/结算（微信授权、地址）
/flash          抢购页（倒计时、限量）
/orders          我的订单（进度跟踪）
```

## 核心能力规划

| 能力 | 说明 | 状态 |
|------|------|------|
| 微信授权 | openid 静默/显式登录 | 规划中 |
| 快速下单 | 私域分享直达结算 | 规划中 |
| 抢购 | 倒计时 + 限量 + 防超卖（后端保障） | 规划中 |
| 订单跟踪 | 查询订单/物流状态 | 规划中 |

## 对接约定（规划）

- 业务接口统一走 backend `/api/*`（经网关），与 App 共用后端聚合订单 API。
